# Euro Truck Simulator 2 - DLC Package

A modern, responsive static website for distributing Euro Truck Simulator 2 DLC packages. Features a beautiful gradient design with animated particle effects and a user-friendly interface.

## 🚛 Overview

This project provides a clean and modern web interface for accessing Euro Truck Simulator 2 DLC resources. The website includes:

- **Version Information**: Displays current DLC package version (v1.57.2.x)
- **Compatibility Badges**: Shows compatibility status with TruckersMP
- **Download Links**: Direct links to DLC files and required components
- **Modern UI**: Gradient backgrounds, glassmorphism effects, and smooth animations
- **Interactive Elements**: Hover effects, particle animations, and responsive design

## ✨ Features

- 🎨 Beautiful gradient purple theme with glassmorphism effects
- ❄️ Animated particle effects (Christmas-themed symbols)
- 📱 Fully responsive design
- 🎯 User-friendly interface with clear download buttons
- ⚡ Fast loading static website
- 🔒 Text selection disabled for cleaner presentation

## 🚀 Usage

Simply open `index.html` in a web browser or deploy to a static hosting service (like GitHub Pages).

The website provides:
- Download link for the DLC package
- Download link for the required `storage.dll` file
- Version and compatibility information

## ⚠️ Important Notes

- **DETECTABLE**: The DLC package is marked as detectable PS: Only in TruckersMP
- **Compatibility**: Compatible with TruckersMP multiplayer (no longer)
